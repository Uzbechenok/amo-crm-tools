# amo-crm-tools 🛠️

Интеграции, виджеты и автоматизация для amoCRM.

## Структура проекта

```
integrations/     # Интеграции с внешними сервисами
widgets/          # Виджеты для интерфейса amoCRM
scripts/          # Скрипты автоматизации
docs/             # Документация
```

## Процесс разработки

1. Задача ставится в `issues` или обсуждается с тимлидом
2. Создаётся ветка `feature/NNN-описание`
3. Разработка → тестирование → сдача
4. После утверждения — merge в `main`
