# Запрос данных для настройки интеграции VK Lead Forms → amoCRM

## Что нужно от клиента для запуска

### 1. VK (сообщество)
- **ID сообщества** (group_id) — числовой ID, берется из URL или из настроек
- **ID лид-форм** (form_ids) — ID тех форм, лиды из которых нужно передавать в amoCRM
- **VK Group token** — создаётся в: Управление → Работа с API → Ключи доступа → права `leads`

### 2. amoCRM
- **Subdomain** — например, `clientdomain` (из URL `clientdomain.amocrm.ru`)
- **Client ID + Client Secret** — для OAuth авторизации (создаются в интеграциях amoCRM)
- **ID ответственного пользователя** — на кого назначать сделки

### 3. Пайплайн
- **ID пайплайна** (воронки)
- **ID статуса (этапа)** — этап "Новые лиды" / "Первичный контакт" и т.д.

### 4. Маппинг полей

| Поле VK | Поле amoCRM |
|---------|-------------|
| Имя (ФИО) | Название сделки / доп. поле |
| Телефон | Контакт (стандартное поле) |
| Email | Контакт (стандартное / доп. поле) |
| Доп. поле 1 | ID кастомного поля в сделке/контакте |
| Доп. поле 2 | ID кастомного поля в сделке/контакте |
| ... | ... |
